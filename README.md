# 🏛️ เว็บไซต์พอร์ทัลบริการประชาชน องค์การบริหารส่วนตำบลเพนียด (อบต.เพนียด)
**Phaniat Subdistrict Administrative Organization Smart Citizen Portal**

ระบบบริการประชาชนอัจฉริยะสำหรับ **องค์การบริหารส่วนตำบลเพนียด** อำเภอโคกสำโรง จังหวัดลพบุรี ยกระดับการให้บริการภาครัฐสู่ยุคดิจิทัล ใช้งานง่าย สะดวก รวดเร็ว และปลอดภัย

---

## 🎨 การออกแบบและธีม (Design & Aesthetic)
- **Theme Color:** สีน้ำเงินตัดทอง (Royal Navy Blue & Royal Gold) สวยงาม ภูมิฐาน ทันสมัย
- **Responsive Web Design 100%:** รองรับการแสดงผลทุกหน้าจออย่างสมบูรณ์แบบทั้ง **Mobile, Tablet, และ Desktop**
- **เทคโนโลยี (Tech Stack):** HTML5 + CSS3 + Vanilla JavaScript (ES6 Modules) โดยไม่ใช้ Framework หนัก

---

## 🌟 ฟังก์ชันหลักของระบบ (Core Features)

1. **📱 ระบบสมัครสมาชิกและเข้าสู่ระบบด้วยเบอร์โทรศัพท์ (Phone Auth & OTP Simulation)**
   - ยืนยันตัวตนผ่านเบอร์โทรศัพท์มือถือ 10 หลัก
   - ระบบจำลอง OTP 60 วินาที พร้อมปุ่มกรอกอัตโนมัติ
   - หน้าโปรไฟล์ประชาชน แสดงข้อมูลและประวัติการใช้งาน
2. **🚨 ระบบแจ้งเหตุฉุกเฉินและสาธารณภัย 24 ชม. (Emergency Reporting)**
   - แจ้งอุบัติเหตุ เพลิงไหม้ ผู้ป่วยฉุกเฉิน สัตว์ร้ายเข้าบ้าน
   - ดึงพิกัด GPS อัตโนมัติ พร้อมแผนที่ Interactive Map ปักหมุดระบุตำแหน่ง
   - แนบรูปถ่ายสถานที่เกิดเหตุ
   - รหัสติดตามเหตุ (Tracking Code) และไทม์ไลน์การเข้าช่วยเหลือของชุดกู้ชีพ
3. **💳 ระบบชำระค่าบริการและภาษีออนไลน์ (Smart E-Payment)**
   - ชำระภาษีที่ดินและสิ่งปลูกสร้าง, ภาษีป้าย
   - ชำระค่าน้ำประปา อบต.เพนียด
   - ชำระค่าธรรมเนียมเก็บขยะมูลฝอย
   - สร้าง QR Code พร้อมเพย์ (PromptPay Thai QR) แบบไดนามิก
   - ออกใบเสร็จรับเงินอิเล็กทรอนิกส์ (E-Receipt) ที่สามารถสั่งพิมพ์ (Print) ได้ทันที
4. **⚖️ ศูนย์รับเรื่องราวร้องทุกข์ / ร้องเรียน (Complaints & Grievances)**
   - แจ้งปัญหาถนนชำรุด ไฟฟ้าดับ ขยะตกค้าง ท่อระบายน้ำ มลพิษ
   - ปักหมุดพิกัดบนแผนที่และแนบรูปภาพ
   - รองรับการร้องเรียนแบบไม่เปิดเผยตัวตน (Anonymous)
   - ระบบติดตามสถานะการดำเนินงานของกองช่าง
5. **📰 ศูนย์ข่าวสาร ประชาสัมพันธ์ และกิจกรรม (News & Events Center)**
   - ข่าวประชาสัมพันธ์ กิจกรรมชุมชน จัดซื้อจัดจ้าง สาระน่ารู้
   - ค้นหาข่าวแบบเรียลไทม์ และตัวกรองหมวดหมู่
   - หน้าต่างอ่านเนื้อหาฉบับเต็มพร้อมแกลเลอรีภาพ
6. **🛠️ แผงควบคุมเจ้าหน้าที่ อบต. จำลอง (Officer Simulation Portal)**
   - ปุ่มสลับมุมมองเจ้าหน้าที่เพื่อทดสอบการรับเรื่องและอัปเดตสถานะแบบครบวงจร

## 🚀 วิธีการติดตั้งและเปิดใช้งาน (Getting Started)

### 1. เรียกใช้งานด้วย Python Server
```bash
py -m http.server 5173
```
หรือ
```bash
python -m http.server 5173
```

### 2. เรียกใช้งานด้วย Vite (หากติดตั้ง Node.js)
```bash
npm install
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:5173`

│   │   ├── base.css         # CSS Reset และ Base Typography
│   │   ├── layout.css       # Header, Hero Banner, Footer, Drawer
│   │   ├── components.css   # Buttons, Modals, Forms, Badges, Tabs
│   │   ├── emergency.css    # สไตล์แผนที่ GPS และแจ้งเหตุฉุกเฉิน
│   │   ├── payment.css      # สไตล์ PromptPay QR และใบเสร็จรับเงิน
│   │   ├── news.css         # สไตล์การ์ดข่าวสารและโมดัลบทความ

│       ├── main.js          # จุดศูนย์กลางเชื่อมต่อทุกโมดูล
│       ├── store.js         # จัดการ State และ LocalStorage
│       ├── auth.js          # ระบบสมาชิกและยืนยัน OTP เบอร์โทรศัพท์
│       ├── emergency.js     # ระบบแจ้งเหตุฉุกเฉิน แผนที่ GPS และ Tracking

│       ├── news.js          # ระบบแสดงข่าวสาร ตัวกรอง และค้นหา
│       └── admin.js         # แผงควบคุมเจ้าหน้าที่จำลอง
